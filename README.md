# Etch-a-Sketch
*Etch a sketch* is a project that aims to deepen the fundamentals of web development, particularly focusing on *flexbox, inheritance, blurs, media queries, container queries, event listeners*.

The project involves creating a colorful sketch on an etch pad with a glassy feel. Users can hover over the sketch to see the changes in color and opacity of the boxes. The project also introduces the concept of taking in and evaluating user input and responding to it appropriately.

## Key features 

- User input: The project takes in user input (a number) and creates a grid of boxes that react to the user’s hover.
- Hover feature: The hover feature triggers the change of color of the boxes. The color of the boxes changes with varying opacity for the first 10 hovers.
- Randomized color textures: The project produces randomized color textures for each turn, adding a touch of uniqueness to the sketch.
- Glassy feel: The etch pad has a glassy feel with a little blur for a more pleasing user experience.

##  Conclusion
Overall, the project is a valuable resource for anyone looking to improve their understanding of web development fundamentals. It provides a hands-on experience with flexbox, inheritance, blurs, media queries, container queries, event listeners, and *functional programming* (see what I did there 😉). While the project has its limitations, such as the lack of accessibility for varying screen sizes, it is still a noteworthy experience.
